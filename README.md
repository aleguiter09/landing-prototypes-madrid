# Fisioterapia Estrella - Landing Page Prototype

**PROTOTIPO / DEMO**: Modern mobile-first landing page prototype for Fisioterapia Estrella, a Madrid physiotherapy clinic.

⚠️ **This is a demonstration prototype, not the official clinic website.**

---

## 🏥 About Fisioterapia Estrella

**Location:** Calle Antonio Casero, 12 · Madrid (Retiro/Pacífico)  
**Contact:** Tel [915 733 915](tel:+34915733915) · [fisioterapiaestrella@gmail.com](mailto:fisioterapiaestrella@gmail.com)  
**Official site:** [fisioterapiaestrella.com](https://fisioterapiaestrella.com/)

### Features

- **Modern mobile-first responsive design** with professional sage/teal palette
- **Clean, accessible interface** using Inter/Libre Franklin fonts
- **Sticky header** with prominent call-to-action
- **Fixed mobile CTA bar** for easy booking on mobile devices
- **Real clinic content:** services, pricing, contact info, and patient reviews from Google Maps
- **Professional presentation** of therapies, pricing transparency, and location details

### Content Sections

1. **Hero** — Welcoming introduction to personalized treatment
2. **Trust/Experience** — Professional credentials and clinic photos
3. **Services** — 6 therapy specialties (Rehabilitation, Manual Therapy, RPG, Sports Physio, Respiratory, Neurorehabilitation)
4. **Pricing** — Transparent pricing (First session 40€, Individual 35€, 10-session package 315€)
5. **Reviews** — Real Google Maps patient testimonials with interactive slider
6. **Contact** — Hours, phone, email, address with Google Maps link
7. **Footer** — Clinic details and copyright

## 🚀 How to Preview Locally

### Option 1: Direct file open
Open `index.html` directly in your browser.

### Option 2: Local HTTP server (recommended)

**Node.js:**
```bash
npx serve .
# Opens at http://localhost:3000
```

**Python 3:**
```bash
python -m http.server 8000
# Opens at http://localhost:8000
```

**Python 2:**
```bash
python -m SimpleHTTPServer 8000
```

## 🎨 Design Details

- **Color Palette:** Professional sage/teal (`#1F6B6B`, `#0E7C8B`) with clean whites
- **Typography:** Libre Franklin for readability
- **Responsive:** Mobile-first with tablet/desktop breakpoints (640px, 768px, 1024px)
- **Accessibility:** High contrast ratios, semantic HTML, ARIA labels
- **Interactive Elements:** 
  - Reviews slider with scroll snap and dot navigation
  - Sticky header with phone CTA
  - Fixed mobile bottom bar (Tel + Email)
  - Hover states and smooth transitions
