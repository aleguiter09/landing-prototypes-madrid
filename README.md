## 🚀 How to Preview Locally

### Option 1: Direct file open
Open `index.html` in your browser, then navigate to the Estrella prototype.

### Option 2: Simple HTTP server (recommended for full features)

**Node.js:**
```bash
npx serve .
# Opens at http://localhost:3000
```

**Python 3:**
```bash
python -m http.server 8000
# Opens at http://localhost:8000
```

**Python 2:**
```bash
python -m SimpleHTTPServer 8000
```

Then navigate to the prototype at `/sites/fisioterapia-estrella/index.html`
