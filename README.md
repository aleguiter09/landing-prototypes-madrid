## 🚀 How to Preview Locally

### Option 1: Direct file open
Open `index.html` in your browser to see the hub, then navigate to any prototype.

### Option 2: Simple HTTP server (recommended)

**Node.js:**
```bash
npx serve .
# Opens at http://localhost:3000
```

**Python 3:**
```bash
python -m http.server 8000
# Opens at http://localhost:8000
```

**Python 2:**
```bash
python -m SimpleHTTPServer 8000
```

Then navigate to individual prototypes or browse from the hub.

- **Mobile-first responsive design** with sage/teal calm palette
- **Inter font** from Google Fonts for modern readability
- **Shared CSS design system** with per-client color variations
- **Sticky mobile CTA bars** (WhatsApp + Tel) on mobile devices
- **Card-based layouts** (no broken tables)
- **AA contrast compliance**
- **Prominent PROTOTIPO disclaimer badges**
- **No invented pricing** (except Estrella which uses real existing prices)
